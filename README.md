# 🚀 VibeCraft AI

**VibeCraft AI** is a beginner-friendly AI prompt generator that helps non-technical "vibe coders" generate bulletproof, hallucination-free prompts.

## ✨ Features
- 🌐 Choose from Web AI, IDE/Cursor, or Command Line app types
- 🧠 Dynamic AI model recommendations (DeepSeek, Claude)
- ⏱ Time & efficiency predictor
- 🎒 Custom idea grab bag
- 📥 Download and 📜 history features
- 🌙 Dark mode "spaceship control panel"

## 🛠 Tech Stack
- HTML5
- CSS3 (with CSS variables for theming)
- Vanilla JavaScript (no frameworks)
- GitHub Pages for hosting
